# ResistorIQ

ResistorIQ is a resistor tester I'm making for the Hack Club 8-Pin Grant.

The idea is to plug in a resistor, select one of four reference resistors using the rotary switch, and have the device measure its resistance. The result will show up on a 16x2 LCD.

I'm using an ATtiny412 microcontroller and designing the PCB in KiCad. The board has two layers and includes the measurement circuit, rotary switch, and connectors.

I've finished the schematic and PCB layout and generated the manufacturing files. Next I need to get the board made, put everything together, program the microcontroller, and test it.

I'll keep updating this repository as the project progresses.
